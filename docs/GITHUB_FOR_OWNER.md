# GITHUB_FOR_OWNER — the two things only you can do 🖱️

Everything else on the repo is already configured via the API. These two are
UI-only (GitHub doesn't expose them to the API), each is literally two clicks:

## 1. Upload the social preview image

1. The image is on your Desktop: **`TalentGraph-social-preview_UPLOAD-THIS-1280x640.png`**
2. Open: https://github.com/Nihal-MN/talentgraph-ai/settings
3. Scroll to **Social preview** → **Edit** → **Upload an image** → pick that PNG → Save.

*(Same flow as Projects 1 and 2 — tell me "done" and I'll verify it's serving correctly.)*

## 2. Pin the announcement discussion

1. Open: https://github.com/Nihal-MN/talentgraph-ai/discussions
2. Open the **"Welcome to TalentGraph AI"** discussion (in Announcements)
3. Right side → **Pin discussion**.

That's it. When both are done, tell me and I'll re-verify the live repo state
(social preview hash + pinned discussion) like I did for the previous projects.
